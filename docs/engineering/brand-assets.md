# ARES logo assets

ARES uses a network-framed A to represent connected supply-chain operations, a teal flow line for movement, and an amber signal for risk and intelligence. The app icon reduces the idea to a legible A with a route node for small sizes.

## Logo variants

| Asset | Use |
| --- | --- |
| `frontend/public/brand/ares-logo-horizontal.svg` | Primary horizontal lockup for documents, presentations, and wide headers on light backgrounds. |
| `frontend/public/brand/ares-logo-stacked.svg` | Centered or square layouts such as title pages and cover slides. |
| `frontend/public/brand/ares-symbol.svg` | Standalone network mark when the ARES name appears nearby. |
| `frontend/public/brand/ares-app-icon.svg` | Compact app mark for the dashboard sidebar and sign-in screen. |
| `frontend/public/brand/ares-logo-mono.svg` | Single-color reproduction for monochrome printing and constrained media. |
| `frontend/public/favicon.svg` | Browser tab icon. |

The dashboard uses the compact mark next to a live text wordmark, which keeps the app navigation accessible and responsive. All variants are SVG so they remain crisp at different sizes. The primary lockup is intended for light backgrounds; use the monochrome mark on a dark surface only after checking contrast in the target placement.

Keep the deep teal, dark blue-green, and amber palette consistent with the product interface. Avoid stretching, recoloring only part of a mark, placing it over a busy background, or using the detailed network symbol at favicon size.
