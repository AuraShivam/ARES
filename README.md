# ARES

Autonomous Resilient Enterprise Supply Chain: a supply-chain visibility and disruption-response MVP for the SAP Hackfest.

The application lives in [`sap-purchase-order-project/`](sap-purchase-order-project/README.md). It includes a Django REST API, a React dashboard, local SQLite-backed demo data, and transparent human-reviewed risk scoring.

HANA access has not been verified. The app intentionally remains on SQLite and makes no SAP connection. See the application README for setup and API details.
